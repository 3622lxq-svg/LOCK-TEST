# LockPlan V2.1 — 闹钟可靠性修正版

本版本重点修复 OPPO/ColorOS 实测中“已开精确闹钟权限但到点不响、不亮屏”的问题。

## V2.1 修复

- 将“通知权限 / 精确闹钟 / 全屏亮起”三个权限状态分开显示。
- 增加“20 秒后测试闹钟”，不用反复新建任务即可测试。
- 精确提醒优先使用 `AlarmManager.setAlarmClock()`。
- 到点后启动独立前台闹钟服务，使用 ALARM 音频通道持续响铃并持续震动，避免只依赖通知频道铃声。
- 前台服务持有短时 WakeLock，增强熄屏状态触发可靠性。
- 仍通过 Full-screen Intent 尝试点亮锁屏并显示闹钟页面；Android/ColorOS 不允许时会降级。

## 首次测试建议

在“提醒与亮屏”中确认三个状态：通知权限、精确闹钟、到点全屏亮起。然后点“20 秒后测试闹钟”，立刻锁屏。

# LockPlan V2 — 锁屏计划

这是针对 OPPO Find X7 Ultra / Android 的 LockPlan V2。

## V2 已实现

- 不再使用常驻“锁屏通知列表”。
- 从手机相册选择自己的图片作为锁屏底图。
- 在自己的壁纸上叠加半透明待办卡片，并只设置为锁屏壁纸。
- 修改、新建、完成待办后自动刷新锁屏壁纸。
- 待办可设置日期、时间、重要标记。
- 待办可设置闹钟提醒：响铃、震动、到点亮屏。
- 支持“完成”和“10 分钟后提醒”。
- 支持卡片透明度、显示条数（3–9）、位置、磨砂/极简样式、是否显示完成项。
- 手机重启、日期变化、时区/时间变化后会重新排闹钟并刷新壁纸。

## Android 系统限制

- 锁屏壁纸是静态图片，因此壁纸上的任务本身不能上下滚动。V2 通过“显示 3–9 条 + 还有 N 项”处理任务较多的情况。
- 系统 AOD（真正的息屏显示）不是普通第三方 App 可任意绘制的区域；V2 保证的是“手机亮起进入锁屏后，壁纸上的待办立即可见”。
- “到点亮屏”通过 Android 的高优先级闹钟/全屏提醒能力实现。Android 14+ 可能要求用户额外允许全屏提醒。
- Android 12+ 如未允许“闹钟和提醒”，系统可能把提醒延迟；App 内提供权限入口。

## GitHub 自动生成 APK

项目自带 `.github/workflows/build-apk.yml`。

上传/提交到 GitHub 后：
1. 进入仓库 `Actions`
2. 打开 `Build Android APK`
3. 等待绿色勾
4. 在页面底部 `Artifacts` 下载 `LockPlan-V2-apk`
5. 解压得到 `app-debug.apk`

## 建议首次测试顺序

1. 安装 APK，允许通知权限。
2. 点“选择我的壁纸”，选择你原来的锁屏壁纸。
3. 新建 3 个今天的任务，分别设置时间。
4. 点“应用到锁屏”，熄屏再亮屏检查显示效果。
5. 新建一个 2–3 分钟后的测试任务，开启“到点提醒”和“到点亮屏”。
6. 按 App 提示开启“精确闹钟”和“全屏提醒”权限，再锁屏等待测试。
